# Published modified 12-6-4 Mg applicability — 14 September 2026

**This candidate has a documented default interaction rule and reusable
parameter data, but it is not yet a supported replacement for the complete
6OIM complex.** The assessment identifies a single missing atom-type lookup,
a water-model change, an unresolved GDP/protein transfer, and a GROMACS
representation gap. Missing site-specific fitting is distinguished from
missing mathematical coverage throughout. No app parameter, topology or
trajectory was changed, and no MD or QM was run.

The [machine-readable inventory](panteva-applicability.json) was generated by
[inventory_panteva.py](inventory_panteva.py). It records all 72 native atom
types, component counts, charge ranges, current LJ parameters, source
polarizabilities, source-rule C4 arithmetic, native class sharing, mapped site
atoms, water/counterion differences, source hashes, licenses and engine limits.

## What the published model provides

Panteva, Giambașu and York's model adds an attractive C4/r⁴ term to the usual
12-6 potential. Its baseline combining rule uses the partner polarizability
relative to water. Selected phosphate and purine interactions receive fitted
corrections. The inspected paper uses TIP4P-Ew for these fits; its DMP and
nucleoside tests and RNA application do not establish complete KRAS/GDP/Ser17
or covalent-adduct accuracy. [Primary paper, Methods and Tables 1–2](https://theory.rutgers.edu/resources/pdfs/Panteva_JChemPhysB_2015_v119_p15460.pdf)

The three Mg corrections below agree independently between the main table,
[SI Table S1](https://doi.org/10.1021/acs.jpcb.5b10423.s001) and the installed
Amber parameter data. Values in this report are source evidence, not assigned
DynaMol parameters.

| Source partner | Amber key | Modified α (Å³) | Modified C4 (kcal Å⁴/mol) |
| --- | --- | ---: | ---: |
| DMP nonbridging oxygen | OPMG | 0.170 | 21.250 |
| Adenosine N7 | NAMG | 1.910 | 238.750 |
| Guanosine N7 | NGMG | 1.925 | 240.625 |

The bundled source gives Mg Rmin/2 = 1.436 Å, ε = 0.02236885 kcal/mol,
C4(Mg–water) = 180.5 kcal Å⁴/mol and α(water) = 1.444 Å³. The script checks
the three fitted C4 values against `180.5 × α / 1.444` with an absolute
tolerance of 10⁻¹⁰. The unmodified source rule therefore defines values for
ordinary protein and ligand types without requiring an individual fitted
override for each pair.

## Coverage of the actual complete system

The unchanged corrected topology contains 27,477 atoms. Its hashed assembly
record retains the deposited Mg, GDP, covalent drug and all 207 deposited
waters, with an empty excluded-environment list. Bulk solvation brings the
water count to 8,218. The COV residue includes the bonded drug–cysteine unit.

| Component | Atoms | Component/type entries | Polarizability lookup after documented GDP alias resolution |
| --- | ---: | ---: | --- |
| Protein | 2,693 | 28 | 28 available |
| Covalent drug residue | 82 | 25 | 24 available; c6 missing |
| GDP | 40 | 21 | 21 available |
| Mg | 1 | 1 | Available; no distinct Mg–Mg pair occurs here |
| Sodium counterions | 7 | 1 | Available; counterion model policy still needed |
| TIP3P water | 24,654 | 2 | Available names; incompatible water family for reproducing this fit |

Component/type counts overlap where components share types. Across the whole
system, 50 of 72 names match directly; resolving the 21 **recorded** GDP
aliases yields 71 of 72. This inspection does not rename atoms or change
their parameters.

The remaining lookup gap is **GAFF2 c6 on four drug atoms**: native indices
191, 192, 241 and 242, mapped to MOV C19, C20, C17 and C18. Their polarizability
is absent from the inspected source table. c6 shares native LJ class 13 with
c3, but equal LJ parameters do not supply missing polarizability provenance.
Neither a zero value nor a borrowed c3 value was inserted.

The coordinating GDP O2B is `QR → O3`, charge −0.9552 e. The source has an O3
default, α = 0.569 Å³, giving C4 = 71.125 kcal Å⁴/mol. **That is defined
baseline coverage, not the DMP correction.** Applying the DMP value 21.25 to
the retained Meagher–Redman–Carlson GDP(−3) diphosphate needs a transfer
assessment. The inspected source does not provide a GDP-specific fit. Ser17
OG likewise has a defined OH default, α = 0.637 and C4 = 79.625, without
complete protein-site validation.

Selective corrections also require careful topology indexing. The five GDP
nonbridging oxygens share LJ class 6 with **241 other atoms**, including
protein oxygens and GDP O6. GDP N7 shares class 1 with **237 other atoms**.
Changing either entire class would alter unrelated interactions. Separate
nonbonded type indices and an explicitly mapped pair matrix are required if
these site corrections are later justified. Merely editing the visible atom
type name is insufficient.

## Water and counterions are part of the model

Current waters have three atoms, charges −0.834/+0.417/+0.417 and no virtual
site. The pinned TIP4P-Ew source has charges 0/+0.52422/+0.52422/−1.04844,
with its fourth site 0.125 Å from oxygen; it also has different oxygen LJ
parameters. Reproducing this candidate requires converting **all** retained
and bulk waters, including the four mapped Mg-coordinating waters. Replacing
only Mg or retaining TIP3P is not the published model. Amber's separate
TIP3P baseline Mg C4 of 132.9 does not establish a TIP3P version of the fitted
corrections.

The inventory records the current sodium parameters and both available
TIP4P-Ew source families. The SI cites Joung–Cheatham NaCl. With Mg alone
selected as a 12-6-4 center, Amber's default rule defines a Mg→Na contribution
of 31.1875 kcal Å⁴/mol. Selecting Na as another 12-6-4 center adds a reverse
contribution and changes the ion model; it is not implied by Mg selection.
No counterion policy was chosen in this audit.

## Native engine representation

**OpenMM:** the inspected 8.5.1 Amber parser recognizes
`LENNARD_JONES_CCOEF` and constructs a `CustomNonbondedForce` carrying the
pair-indexed −C4/r⁴ term, with the correct 4.184×10⁻⁴ unit conversion. It
copies exceptions into exclusions and uses periodic cutoffs with a long-range
correction for C4. This is source-code evidence, not an executed validation
of this candidate or the packaged app path. Mapping, exclusions, virtual
sites, energy/force, cutoff/tail and virial checks remain necessary.

**GROMACS:** the inspected ParmEd 4.3.1 `.top` writer emits conventional
LJ/NBFIX terms and has no C4 transport path. Standard nonbonded type/pair
fields do not encode an independent C4. Moreover, tagged GROMACS 2025.4
documentation marks User nonbonded tables unsupported, and its preprocessor
allows only cut-off or PME LJ with Verlet lists. The older-looking reference
manual table overview must not be mistaken for supported functionality in
this bundled version. [Tagged options source](https://github.com/gromacs/gromacs/blob/v2025.4/docs/user-guide/mdp-options.rst),
[tagged preprocessing source](https://github.com/gromacs/gromacs/blob/v2025.4/src/gromacs/gmxpreprocess/readir.cpp),
[topology parameter format](https://manual.gromacs.org/2025.4/reference-manual/topologies/parameter-files.html)

A separately verified exact additional-pair-force implementation or engine
extension would be needed for this candidate in GROMACS. This is a limitation
of the inspected workflow, not a claim that implementing 12-6-4 in GROMACS
is impossible in principle. No approximation or restraint was substituted.
