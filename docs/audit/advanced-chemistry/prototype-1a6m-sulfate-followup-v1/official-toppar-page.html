The CHARMM topology files used in PDB Reader are list below. The residues in the PDB file that users want to read must be defined in these topology files. Otherwise, CHARMM will be terminated abnormally.

Please use the following website to obtain the official CHARMM additive FFs: http://mackerell.umaryland.edu/charmm_ff.shtml
