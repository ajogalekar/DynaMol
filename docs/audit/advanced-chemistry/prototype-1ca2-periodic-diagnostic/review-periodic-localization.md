# 1CA2 periodic energy discrepancy: bounded independent review

The absolute periodic-energy comparison still does **not** pass. The new evidence localizes most of the discrepancy to **thread-sensitive direct-space Coulomb bookkeeping/accumulation**, rather than the reciprocal mesh energy alone. It does not identify a particular floating-point operation as the sole cause, and no energy offset has been subtracted.

Three fresh, zero-step native calculations reused the identical pre-existing `matched-mesh/diagnostic.tpr` (SHA-256 `5aa9285424526503ae95aebc3c786baf5c318ea86fbbdac3a12fe276b2ac3ac2`). This is GROMACS 2025.4 mixed precision on ARM_NEON_ASIMD, one MPI rank, CPU nonbonded evaluation, with PME tuning disabled. The TPR fixes alpha 3.2893431387452243 nm⁻¹, order 5, grid 150 × 147 × 168, and 1 nm cutoff. Every saved atom coordinate and periodic box is exactly equal across these evaluations and to the saved OpenMM reference input. No dynamics, QM, parameter changes, or central code changes were performed.

OpenMM Reference potential is −429191.2916377305 kJ/mol. Changing only the native thread count changes total energy by **41.718750 kJ/mol**, of which **41.562500 kJ/mol** appears in Coulomb SR and only 0.204101 kJ/mol in reciprocal energy. Its force change relative to the original GROMACS evaluation is just 0.0001746 kJ/mol/nm RMS vector difference. The two-thread repeat reproduces the displayed energy components exactly; its tiny force differences are consistent with nondeterministic reduction order. The plain-C diagnostic changes more than SIMD precision: the documented source switch also selects tabulated exclusions and changes pair-list/kernel behavior. Its result does not isolate SIMD arithmetic as a cause and does not resolve the offset.

The pinned upstream source explains why comparing the two programs' raw reciprocal components is misleading. GROMACS computes the Ewald self correction in the short-range kernel and adds it to its Coulomb energy accumulator ([SIMD kernel, lines 351–364](https://github.com/gromacs/gromacs/blob/v2025.4/src/gromacs/nbnxm/simd_kernel.h#L351), [self-energy definition](https://github.com/gromacs/gromacs/blob/v2025.4/src/gromacs/nbnxm/simd_coulomb_functions.h#L137)). Using the saved OpenMM charges, alpha and Coulomb constant gives a self-energy magnitude of 2,841,386.045346 kJ/mol. Adding this back to the saved OpenMM CPU reciprocal component gives approximately 3962.083496 kJ/mol, versus GROMACS 3961.899902: a **−0.183594 kJ/mol** discrepancy. This estimate is explicitly a bookkeeping localization using the already-saved CPU decomposition, not a new double-precision component-parity result; CPU/Reference total energies also differ by about 0.095 kJ/mol. The separately recorded dispersion-correction difference is only about −0.457 kJ/mol.

The source makes finite-precision accumulation a credible mechanism: the short-range accumulator uses `real` and `SimdReal` buffers, including the self correction, while PME's energy accumulator also uses `real` ([direct-space accumulator](https://github.com/gromacs/gromacs/blob/v2025.4/src/gromacs/nbnxm/simd_energy_accumulator.h#L160), [PME solver](https://github.com/gromacs/gromacs/blob/v2025.4/src/gromacs/ewald/pme_solve.cpp#L302)). In contrast, global charge and squared-charge sums use **double**, so a naive float summation of the global squared charges is not a supported explanation ([forcerec.cpp](https://github.com/gromacs/gromacs/blob/v2025.4/src/gromacs/mdlib/forcerec.cpp#L397)). A thread-dependent direct-space sum, which mixes a large self term with pair/exclusion contributions, fits the observations. The evidence is insufficient to claim this fully accounts for every residual or all architectures.

If absolute-energy parity needs further resolution, the next discriminating experiment is the same static comparison with a **pinned double-precision GROMACS build**, keeping the physical model and matched PME settings fixed, then checking direct-space components, reciprocal components and forces. That build/test has not been run. Close forces and intact coordination support the separately reported short motion check; they do not validate absolute periodic energies, long-term dynamics, native site accuracy, or the remaining metal-protein panel.
