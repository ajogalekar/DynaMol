# Pinned upstream reference sources

These unmodified source snapshots support reproducible research checks. Their
upstream copyright and license notices remain in the files; they are not
relicensed under DynaMol's license. `manifest.json` records exact source URLs
and SHA256 hashes. `license-manifest.json` records the accompanying license
texts downloaded from the pinned simple-dftd3 release.

* Psi4 v1.9.1 functional definitions retain the Psi4 developers' LGPL-3.0 notice.
* The DZVP orbital basis retains its Godbout et al. publication attribution and
  original EMSL basis header from Psi4.
* simple-dftd3 v1.6.0 test/parameter sources retain the upstream notices;
  the test source is LGPL-3.0-or-later.
* `COPYING.GPL3` and `COPYING.LESSER.LGPL3` provide the GPL/LGPL v3 terms.

These files are audit inputs, not components added to the DynaMol application
bundle. Runtime distribution would require its own complete dependency and
license review.
