# 1CLL: a modeled additive now has a bounded reconstruction path

The standalone candidate removes the specific two-heavy-anchor reconstruction blocker. It does not create a full prepared protein or a production MD model. The original backend source and its three-anchor admission rule are unchanged. Its exact rejection is retained in `original-rejection.json`.

The frozen 1CLL bytes (SHA256 a8be375d00d2d5d47ffacae491f775167d1c0488ab8485cabd269410e596d3aa) contain EOH153 carbon atoms C1/C2 and a deposited atom explicitly named/typed H21/H. CCD EOH requires oxygen O. The deposited H21 was not relabeled as oxygen. All source ligand records remain in `qualification.json`; generated hydrogen coordinates are separate modeled coordinates. The source contains four Ca ions and 139 waters. All 1,276 other deposited heavy-atom records, including both deposited alternate conformations, were retained in the conservative clash environment.

The candidate admits only neutral, closed-shell, acyclic three-heavy-atom C/N/O graphs with two bonded named heavy anchors and one missing terminal atom. It rejects declared/inferred stereochemistry, external covalent/metal links, extra or duplicate identities, incompatible hydrogen state, and grossly invalid geometry. The hash-verified original `_graph` and `_set_conformer` functions run unchanged against topology metadata objects; this is not an OpenMM simulation or a complete backend invocation.

One seeded ETKDG/MMFF94s reference model preserves both carbon coordinates exactly. Twenty-four rigid rotations around their bond explicitly represent the unresolved orientation. The original 1.6 Å nearest-environment clash cutoff is evaluated using direct NumPy distances. All 24 EOH alternatives survive this coarse screen; candidate 0 is the arbitrary deterministic representative, not a physically ranked or experimentally established pose. Original heavy coordinates have zero displacement. The local MMFF94s energy is used only for constructing the additive and must not be substituted for an Amber/OpenMM ligand force field.

The bounded qualification passed 27 checks, including the actual frozen EOH case, a different missing terminal identity, exact fixed anchors, deterministic repetition, distinct alternatives, severe environmental blockage, invalid graph/state/stereo/link/coordinates, and preservation of the original rejection. One isolated process completed in 5.577 seconds, with 81,068,032 bytes maximum sampled group RSS (50 ms sampling, 2,000,000,000-byte ceiling), one thread requested, and its process group absent afterward. The native test body took 0.047 seconds; library import accounts for most process time. Sampling does not bound between-sample peaks. No QM or MD ran, no active runtime was changed, and no central project status files were edited.

A named calcium candidate is available locally: Li et al. 2013 CM 12-6 Ca2+ matched to TIP3P. The local Amber Rmin/2 and epsilon convert exactly to the local OpenMM TIP3P calcium sigma/epsilon, with +2 charge. This establishes a source-compatible implementation candidate, not accuracy for the four EF-hand sites. The ion paper discusses water-model and electrostatics compatibility; Amber distinguishes 12-6-4 as requiring explicit C4 propagation. Sources: [Li et al. 2013](https://doi.org/10.1021/ct400146w), [Amber ion models](https://ambermd.org/AmberModels_ions.php), [1CLL deposit](https://www.rcsb.org/structure/1CLL), [EOH CCD identity](https://www.rcsb.org/ligand/EOH). API behavior follows the existing implementation and the [RDKit distance-geometry](https://www.rdkit.org/docs/source/rdkit.Chem.rdDistGeom.html) and [fixed-point force-field](https://www.rdkit.org/docs/source/rdkit.ForceField.rdForceField.html) documentation.

The next smallest implementation is an explicit prototype materializer that transfers a reviewed modeled alternative into full preparation while retaining original atom IDs, all four calcium sites, all relevant waters, protein alternate-state decisions, and the complete ethanol graph. It must obtain a complete mapped ethanol force field/charge model through the existing validated ligand path before evaluating a full-system energy and force. No such full-case parameterization or static mechanics is claimed by this package. The proposed additive is suitable as a clearly labeled input hypothesis for that next step; the full 1CLL panel case remains unprepared and unvalidated.

The candidate remains outside backend defaults. Independent review is pending; source/evidence pins are in `artifact-manifest.json`. Calcium and source applicability evidence is in the sibling `1cll-prep-applicability-v1/applicability.json`.
