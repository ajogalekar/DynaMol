# Source identity regression findings

The 15-entry panel was frozen before preparation outcomes in `benchmark-case-selection.json`; full preflight outcomes remain in `benchmark-manifest.json`. These are actual experimental source gaps, not deliberately removed coordinates. The larger convenience inventory is retained in `benchmark-screening-inventory.json`.

Four general import/selection defects were found and repaired before rerunning the same entries:

- **Label versus author chain identifiers:** OpenMM can select either CIF namespace according to source contents. The sequence workflow now joins original CIF atom IDs to the native reader's actual chains, then applies the recorded canonical mapping. For 2CG9, author X / label C now retains both actual internal gaps of seven and two residues.
- **Associated-molecule connection identifiers:** CIF ligands often share an author chain ID with the protein while being separate label chains. Source connection endpoints now resolve their full source residue identity to native chains. This repairs false missing-endpoint errors in 6A93 and 2REN without severing actual covalent links.
- **Insertion codes:** MDTraj does not retain OpenMM insertion codes in its topology conversion. Exact native PDB serialization now precedes canonical topology parsing during source import and monomer extraction, preventing repeated author-number/name residues from collapsing into fewer atoms. Exact blank codes remain distinct from lettered codes, with full chain-order validation retained. The original 1RNE coordinates and repeated author number 281 are preserved.
- **Crystallographic-image links:** OpenMM interprets CIF `struct_conn` records as ordinary bonds without applying the recorded symmetry transform. A private parser view excludes only connections whose two explicit, well-formed image IDs differ; original source bytes and omitted connection IDs are retained. Unknown images are not treated as permission to drop a bond. This repairs the artificial 61/82 Å disulfide connections seen in 4HHY. The monomer workflow also records these external-image connections without treating them as links to loaded atoms.

The targeted source, sequence, and monomer suite passed 48 tests, including six new synthetic controls for insertion-code preservation, shared author/label namespaces, and same/different/unknown image covalent connections. These controls test identity and connectivity preservation, not native conformational accuracy.

The same five-case post-fix preparation run is preserved under `runs/identities-fixed-1`. It produced one genuine final-geometry refusal (2CG9 peptide omega after bounded refinement), three specialized covalent-chemistry refusals (6A93 PLM; 2REN and 1RNE NAG), and the expected 13-residue gap-size refusal (2ITY). The identity repairs therefore removed misleading errors but did not automatically accept unsupported chemistry or invalid geometry. Every original file hash and per-case backend hash remained unchanged during this run. No MD was performed.
