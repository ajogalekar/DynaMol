# Bounded 4BVN loop-repair review

This is a software review by a language model, not an independent certification of a native protein conformation. The original failed preparation (`7438dad9ca5d4476`) remains part of the benchmark evidence. It rejected A:241 ILE CA stereochemistry before ligand parameterization or production dynamics.

The bounded amendment permits at most four PDBFixer construction attempts, four CPU threads and five minutes total. `review-loop-amendment.preflight.json` and `review-loop-amendment.audit.json` record four applicable preflight passes. The bounded review now accepts the final fallback as software behavior, subject to the unchanged geometry guards and required minimization; it does not certify a native conformation. The original five-system manifest is retained unchanged.

Inspection of the installed PDBFixer 1.12 `addMissingAtoms` implementation confirms that original atoms are held massless during local construction and that only new-atom coordinates are copied into the final topology. The seed applies to optional clash-relief Langevin relaxation after deterministic minimization. Its internal relaxation may use up to ten segments of 200 steps at 5 fs, followed by minimization. These are construction operations within the probe budget, not a production trajectory or sampling evidence. If that optional branch is not entered, seed changes may yield identical failures.

The application currently checks input, repaired and final stereochemistry against signed template volumes, with explicit ILE/THR secondary-center checks and modified-residue checks. The proper-rotation Kabsch helper excludes reflected template transforms. A retry or new-sidechain placement must preserve those gates: reset to the original input for each construction attempt; alter only originally absent atoms; preserve source identities and observed coordinates; keep all failed attempts and seeds; check finite coordinates, bonded backbone continuity and each relevant chiral center again. Rebuilding a sidechain in an observed residue must never move its observed atoms.

A first candidate passing these software geometry checks can be described as a low-confidence modeled region. It cannot be called the native loop, a validated binding pose, an independently sampled model, or evidence of receptor behavior. If the bounded attempts fail, preserve the blocker and select a different benchmark structure rather than weaken the chirality test.

This separation of a benchmark failure from claimed scientific accuracy follows the reproducibility and transparent failure-reporting principles summarized in the PatAgent review, including [We Need Better Benchmarks for Machine Learning in Drug Discovery](https://practicalcheminformatics.blogspot.com/2023/08/we-need-better-benchmarks-for-machine.html).
