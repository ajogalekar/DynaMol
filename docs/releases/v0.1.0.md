# DynaMol 0.1.0 — early release

DynaMol is an open-source desktop workspace for creating, viewing and measuring
molecular-dynamics trajectories. This first release is for individual scientists
who want a clear local workflow and visible progress.

## What's included

- OpenMM and GROMACS simulation setup, background progress and native diagnostics.
- Structure loading, supported protein/ligand preparation and explicit warnings
  when chemistry or reconstruction needs attention.
- Ribbon and atom views, water/hydrogen controls, smooth playback, zoom, and
  distance, angle, dihedral and hydrogen-bond measurements.
- Live measurements, RMSD/RMSF, named Projects, saved scenes, portable backups and
  compatible checkpoint recovery.

## Get started

For the source checkout, follow the [README](../../README.md).

The self-contained Mac app targets **Apple Silicon and macOS 14+** and bundles
Python, OpenMM, GROMACS and AmberTools. It needs no separate engine installation.

1. Download the DMG from the release assets and double-click it.
2. Drag **DynaMol** onto **Applications** in the installer window.
3. Open DynaMol from Applications. First launch unpacks its included engines and
   opens the local interface in your browser.

Eject the installer disk when copying has finished. See the asset's matching
checksum and acceptance record for the exact build being downloaded.

This is an **unsigned release**: the launcher has only an ad-hoc signature,
without Developer ID or notarization. macOS may warn about or block a downloaded
copy. Follow [Apple's per-app opening guidance](https://support.apple.com/en-us/102445)
only for a download you trust.

Work is stored in `~/Library/Application Support/DynaMol`. Replacing the app
does not delete it. Closing the browser leaves jobs running; the DynaMol menu
reopens the interface and provides Quit choices. See the [package guide](../PACKAGING.md).

## Checked, with clear limits

Bundled-app acceptance has passed local archive/runtime, both-engine worker,
workspace/project restart, native browser launch and seven Chrome pinch/zoom
checks. Consult the matching acceptance record for the asset build. Those tests
used private bundled runtimes on the
**development Mac**, not a separate clean Mac or the minimum supported OS.
The packaged worker checks were short installation tests.

The separate [source-app pressure test](../audit/five-system-pressure-test/REPORT.md)
completed five 100 ps systems with three OpenMM and two GROMACS runs, and all
five real-trajectory browser audits passed. The final scoped backend suite passed
265 tests. A failed reconstructed GPCR loop was rejected and retained in the
report. These results support software functionality, not physical convergence,
biological stability or universal chemistry support.

The packaged app defaults to **100,000 atoms**, with no larger-profile toggle.
The source service can opt into 200,000; the 145,913-atom GPCR benchmark used that
source profile. Prepared complexes use OpenMM with explicit TIP3P water. Membrane
construction, large-trajectory streaming, unsupported covalent chemistry and
specialized metal models are outside this release. New database fetches need
internet; arbitrary uncached ligand preparation is not guaranteed offline.

## Release assets

Use the DMG, its SHA-256 checksum and the matching acceptance record attached to
the GitHub release. Build IDs and hashes live in those records, so they describe
the exact downloadable files. The source repository and native binaries have
separate distribution records; see [third-party notices](../../THIRD_PARTY.md)
and the corresponding-source materials supplied with binary distribution.
Apple signing is not planned for this unsigned early release.
