# Preparation, import, and solvent-preview review

The reviewed implementation passes the bounded functional, geometric, and state-preservation checks described below. It can prepare supported proteins, attempt short sequence-supported repairs, reject invalid modeled geometry, and carry a prepared hydrogen state and solvent box through OpenMM. These checks do not establish experimental loop accuracy, correct native rotamers, site-specific pKa values, or equilibrium MD behavior.

This is a language-model implementation and evidence review, not certification by an MD or structural-biology expert. PatAgent is a checklist and evidence-retrieval wrapper inspired by public writing; it is not Pat Walters, is not endorsed by him, and does not speak for him.

The exploratory preflight passed six gates. The final automated postflight passed seven gates and blocked the **scientific-promotion uncertainty gate** because no uncertainty intervals or scientific accuracy validation were performed. That limitation is recorded, not converted into a passing claim. Software functionality is supported separately by executable checks. See `audit/preparation-preflight.json`, `audit/preparation-postflight.json`, and `audit/preparation-manifest.postflight.json`.

## Findings resolved during review

| Finding | Current behavior | Evidence |
| --- | --- | --- |
| A missing coordinate residue can leave an artificial long peptide bond even when no sequence record identifies what is absent. | Original sequence bytes are retained. Missing-loop attempts require explicit sequence evidence and opt-in. Numbering gaps never invent residue identities; unresolved long C–N links reject before preparation/simulation. | `preparation-source-checks.json`; `preparation-pdbfixer-inspection.json` |
| mmCIF chain names can change during canonical PDB storage, and sequence records can use label IDs while coordinates use author IDs. | Original-to-canonical and label-to-author mappings preserve the sequence association in both dedicated fixtures. | `preparation-source-checks.json` |
| Interleaved MOL2 residue atoms caused an unhandled topology-write error. | Unsupported interleaved chain/residue blocks and duplicate atom identities reject before storage; serialization failure cleans up the partial import. | `preparation-source-checks.json` |
| Existing hydrogens can survive an automatic pH reassignment unchanged. | Preparation deliberately removes and rebuilds hydrogens. It records actual bonded-H inventories and force-field charges, including states not explicitly named by OpenMM's returned variant list. | `preparation-upstream-protonation.json`; `preparation-pipeline-checks.json` |
| The first missing-ILE3 model had inverted alpha and beta centers despite force-field assignment/minimization. | Template placement uses a scoped proper-rotation alignment. Separate checks reject inverted or near-planar standard CA and ILE/THR CB centers before repair, after repair, and after relaxation. Invalid attempts do not publish prepared datasets. | `preparation-loop-stereochemistry.json`; `preparation-kabsch-reflection.json`; `preparation-geometry-checks.json` |
| Completed simulation datasets initially lost preparation/solvation markers. | Results retain their parent ID, preparation/solvation metadata, and exact first-frame prepared PDB. Reusing a result remains protected from pH reset and duplicate solvation. | `preparation-continuity-checks.json` |

The ILE reflection had a concrete numerical cause: the installed PDBFixer 1.12 template-fit routine returned a transform with determinant −1 for the fixture. Restricting alignment to determinant +1 removes that reflection path. It is insufficient alone: later placement or relaxation can still yield unsuitable geometry, so the stereochemistry checks remain necessary. The historical failing coordinates are retained as regression evidence and are not an accepted current output. The implementation uses a private upstream helper only within the preparation subprocess and restores it afterward; dependency updates require revalidation. Source context: [PDBFixer implementation](https://github.com/openmm/pdbfixer/blob/master/pdbfixer/pdbfixer.py).

## Independent checks and their practical limits

Eight source/inspection groups verify original SEQRES retention, missing-NZ reporting, known versus numbering-only gaps, both mmCIF chain-mapping cases, deterministic seeded SMILES coordinates with stereochemical metadata/warnings, explicit MOL2 rejection, fixed-provider URL validation, and PDB/mmCIF coordinate equivalence. The retained RCSB 1UBQ PDB and mmCIF contain the same 660 atoms and identical coordinate arrays and crystal-box dimensions. These are import checks, not evidence that every supported-format variant is valid.

Actual background preparation restored LYS6 NZ and terminal OXT in a synthetic six-residue peptide. A histidine fragment prepared at pH2 had both ring protons and 132 atoms; re-preparing it at pH7 had one ring proton and 131 atoms. A one-step OpenMM continuation used byte-identical prepared input and retained the pH2 hydrogen inventory. Automatic pH selection is heuristic/template-based; it is not a pKa calculation. [OpenMM Modeller documentation](https://docs.openmm.org/latest/api-python/generated/openmm.app.modeller.Modeller.html) explains why merely calling automatic hydrogen addition again does not remove stale hydrogens.

A **positive loop control** removed ALA28 from a synthetic 1UBQ residues 26–30 excerpt while retaining its sequence. With seed 2026 and optional sidechain optimization disabled, preparation produced a 92-atom model containing ALA28, no long peptide gap, and the expected signs for all six checked CA/ILE-CB centers. The output explicitly labels the rebuilt segment low confidence. See `audit/preparation-positive-loop.json`. This is a software fixture, not an experimentally observed fragment or an accuracy benchmark.

Two other attempts were appropriately rejected: the missing-ILE3 fixture remained stereochemically unsuitable after repair, and the ALA-gap fixture with optional relaxation inverted a retained center. Their rejection is desirable behavior, not a successful structural prediction. The workflow is a bounded attempt and may require external repair. PDBFixer's missing-residue list and missing-atom operation must be controlled together; [the upstream manual](https://github.com/openmm/pdbfixer/blob/master/Manual.html) describes these dependencies.

Four independent geometry groups check that discrete chi rotations lower the stated overlap score, preserve covalent lengths and fixed backbone coordinates, preserve CA handedness, and skip distal covalent crosslinks. They also verify proper alignment and rejection of both centers in the historical bad ILE model. The search is one bounded pass over original/−60°/+60°/180° chi states with a dimensionless steric-overlap objective, followed optionally by at most 150 restrained local minimization iterations. It has no empirical rotamer probabilities or exhaustive packing and does not establish a native sidechain configuration.

Three solvent checks used a 132-atom, pH2 modeled histidine fragment. The real TIP3P preview contained 3,485 atoms with counterions, retained every solute identity and coordinate, preserved both histidine ring protons, reused an identical-settings preview, and rebuilt changed padding from the prepared parent. A one-step periodic OpenMM continuation preserved all 3,485 atoms, exact saved first-frame coordinates, and the box, with no second solvation. The resulting trajectory retained preparation/solvation markers and remained protected from GROMACS state reset. The coordinate error from preview storage to standard PDB reuse was at most 0.0000403 nm in the direct solvent check; the general PDB rounding scale is 0.00005 nm per coordinate. Previews are unequilibrated starting systems.

GROMACS explicitly rejects DynaMol-prepared and solvent-preview states in this version. Five upstream tiny-fragment probes showed that selected HIP/HID, ASH/GLH, and LYN states could preserve coordinates only after state, hydrogen-name, ILE CD1/CD, and terminal oxygen-name mappings. Those experiments do not constitute a complete converter or comprehensive terminal/crosslink/prochiral-name validation. [GROMACS pdb2gmx documentation](https://manual.gromacs.org/documentation/2025.4/onlinehelp/gmx-pdb2gmx.html) describes its independent hydrogen/protonation and atom-reordering behavior.

## Molecular sources and reproducibility

SMILES uses RDKit ETKDGv3 with a recorded seed and checked embedding/minimization outcome; generated coordinates are labeled computed conformers. Input and canonical isomeric SMILES, formal charges, undefined stereocenters, chemistry, and provenance are retained. MOL2 uses a bounded Tripos parser preserving explicit graph/charge data; it is not a universal MOL2/GAFF parser or ligand MD parameterizer. [RDKit documentation](https://www.rdkit.org/docs/RDKit_Book.html) supplies the upstream conformer-generation context.

The complete 91-record public Practical Cheminformatics corpus refreshed during the initial review was searched again for representation, preparation, protonation, validity, and reproducibility. Metadata-only attributed results are retained under `audit/preparation-blog-search-*.json`. [“The Trouble With Tautomers”](https://patwalters.github.io/The-Trouble-With-Tautomers/) motivates distinguishing computational representations from experimentally populated states; applying that principle here is review synthesis, not validation of DynaMol by the author.

`audit/preparation-reviewed-code-sha256.json` records reviewed code hashes and dependency versions. Fixture source hashes, fixed seeds, settings, stage logs, status, metadata, and small coordinate/XML/CSV outputs are retained. Temporary isolated datasets and full one-step trajectory arrays were removed after their assertions; that exclusion is explicit in the manifest. Application jobs retain their full result bundles. Tests can be rerun using the `docs/audit/check_preparation_*.py` scripts. The current backend suite also passed 48 tests (two upstream deprecation warnings); actual output is retained in `audit/preparation-backend-tests.txt`. No replicas, convergence study, uncertainty estimation, scientific method comparison, or experimental validation was performed.
